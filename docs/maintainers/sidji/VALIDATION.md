- The website's broad API request mock intercepted Vite JavaScript modules under `/src/routes/api/`, preventing hydration. It now mocks only actual HTTP paths beginning `/api/`; its assertions and paid-provider isolation remain intact. An initial local network hook also blocked the intended mock-script URL; the adapter now falls back to the existing fulfilled mock. All fourteen browser cases pass.
- The first native harness incorrectly expected a Default project before the UI had bootstrapped it. The real MCP listing was empty, as appropriate for a fresh database. Native verification also waits for the complete dashboard/onboarding rather than accepting its loading skeleton.

Cold-start limits are distinct from application correctness and final warm-runtime results.
- Early website type checking before the full dependency graph was installed failed on an unavailable ancestor Playwright dependency. The completed frozen graph passes the website check; the early attempt is not classified as an upstream source defect.

Builds retain non-failing upstream warnings: large chunks, mixed static/dynamic imports, dependency pure-comment annotations and deprecated inputValidator usage. Knip reports configuration hints. No dependency upgrade or unrelated optimization was introduced to silence them.
