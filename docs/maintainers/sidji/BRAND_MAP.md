The original raster marketing social card is retained with the explicit alt text “Upstream OpenSEO marketing archive”. Its artwork is not redesigned or represented as a SiDJI-created asset. Existing generated title cards use the SiDJI wordmark with their original renderer layout, colors, fonts and canvas. Historical screenshots, testimonial copy and demo media are not rewritten. The marketing archive is not approved for publication.

## Network destinations

- App, assets, reports and MCP: local instance at `http://127.0.0.1:3001`; runtime links use the validated request/browser origin where available.
- Setup, repository and personal maintenance: `https://github.com/fyz-hafiz-98/sidji-seo`.
- DataForSEO, OpenRouter, Google, IndexNow and Cloudflare DNS: official provider endpoints preserved. Live integrations require owner credentials and are not exercised by this task.
- OpenSEO docs/community/legal/billing/marketing content: retained upstream provenance where appropriate, classified explicitly. No SiDJI hosted subscription, support mailbox or public domain exists.
- PostHog/self-host heartbeat: existing engine preserved, disabled in personal environment templates. Hosted-only billing/referral/email code remains inactive in local mode.

## Residual policy

The executable residual check uses explicit path/pattern rules with reasons. App-facing product copy and operational hosted fallbacks are not blanket-allowed. Test data containing OpenSEO/openseo.so is provider/user fixture data and must not be rewritten as SiDJI customer data. Documentation about the upstream, technical identifiers, generated compatibility names, and archived marketing material may legitimately retain the old name. Generated plugin workflows must match their edited source.
